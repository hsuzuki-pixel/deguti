# deguti

YouTube風のホームページを静的ファイルで作成しています。

## 使い方

`index.html` をブラウザで開くと表示できます。

例:

```bash
xdg-open index.html
```
## 幸せ経営コンパス（`lifeplan/index.html`）

社長・幹部のライフプランと経営計画を連動させ、予算3案と資金繰り予想・予実差異と期末着地予測・BS目標・銀行格付け・生命保険の適正化診断・M&A出口（バイアウト目標）・面談レポート出力と「5つの基本的欲求」（選択理論）の充足度で経営者層の幸せを伴走管理するソフトです。ブラウザで開くだけで動き、入力内容はブラウザに自動保存されます（「データ」タブで書き出し・読み込み）。事務所内での共有保存は claude.ai 上で開いたときに使えます。
