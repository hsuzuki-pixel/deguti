# deguti

YouTube風のホームページを静的ファイルで作成しています。

## 使い方

`index.html` をブラウザで開くと表示できます。

例:

```bash
xdg-open index.html
```

---

# クロスセル・ナビ（`crosssell/`）

M&Aで承継した会計事務所のクライアント（経営者）ごとに、
**生命保険・損害保険・M&A（事業承継）・不動産購入** のニーズを自動判定して一覧で見るツールです。

## 起動・配布

インストール不要です。

- **配布版（おすすめ）**：`crosssell/dist/crosssell-navi.html` の1ファイルだけで動きます。メール添付や共有フォルダで職員に配布し、ダブルクリックでブラウザ（Chrome / Edge 推奨）で開いてください。
- **開発版**：`crosssell/index.html` を開きます。

データは各パソコンのブラウザ内（localStorage）に保存されます。**定期的に「データ取込・出力」→「バックアップを保存」**してください（7日以上バックアップが無いとダッシュボードに警告が出ます）。別のパソコンへの移行もバックアップファイルで行えます。

操作手順はアプリ内の「操作ガイド」にまとめています。

## 開発者向け

```bash
node crosssell/build.js            # 配布版 dist/crosssell-navi.html を作成
node crosssell/tests/smoke.js      # 動作確認テスト（開発版）
node crosssell/tests/smoke.js --dist  # 動作確認テスト（配布版）
```

テストには Playwright（Chromium）が必要です。

## 画面

| 画面 | 内容 |
|---|---|
| ダッシュボード | KPI、カテゴリ別ニーズ分布、優先アクションTOP10、クライアント×商品のニーズ・マトリクス（ヒートマップ） |
| クライアント一覧 | 財務数値と各ニーズの判定結果。並べ替え・絞込み（引継ぎ元事務所／業種／担当／ニーズ度） |
| クライアント詳細 | 判定理由・提案メニュー・試算値（保障不足額、退職金目安、簡易企業価値、取得予算）、進捗管理、面談メモ、印刷 |
| 提案パイプライン | 未着手→提案準備→提案中→成約／見送り のカンバン |
| 回収シミュレーション | 事務所の買収価格を「顧問料のみ」と「顧問料＋クロスセル期待収益」で何年で回収できるか試算。前提条件（成約確率・手数料率・解約率等）は画面で変更可 |
| 会計データ取込 | 会計ソフト（弥生・freee・MF・勘定奉行・JDL等）の試算表／決算書CSVから財務数値を自動反映。Shift_JIS/UTF-8自動判別、△マイナス表記、円/千円の単位推定、期中試算表の年換算に対応 |
| データ取込・出力 | CSVテンプレート／一括取込、CSV出力、バックアップ・復元（前提条件を含む） |
| 操作ガイド | 導入〜提案〜回収管理の手順、判定の考え方、FAQ、コンプライアンス上の注意 |

## ファイル

- `crosssell/scoring.js` … ニーズ判定ロジック（ルールはここで調整）
- `crosssell/sample-data.js` … デモ用の架空クライアント30社
- `crosssell/economics.js` … 想定手数料・回収シミュレーションの計算
- `crosssell/finance-import.js` … 試算表・決算書CSVの読取り（勘定科目名で判定）
- `crosssell/app.js` … 画面・操作
- `crosssell/styles.css` … デザイン（ライト／ダーク対応）
- `crosssell/build.js` … 1ファイル配布版の作成
- `crosssell/tests/smoke.js` … 動作確認テスト
