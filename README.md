# クロスセル・ナビ（`crosssell/`）

M&Aで承継した会計事務所のクライアント（経営者）ごとに、
**生命保険・損害保険・M&A（事業承継）・不動産購入** のニーズを自動判定して一覧で見るツールです。

## 起動

インストール不要です。`crosssell/index.html` をブラウザで開いてください。
データはブラウザ内（localStorage）に保存されます。

## 画面

| 画面 | 内容 |
|---|---|
| ダッシュボード | KPI、カテゴリ別ニーズ分布、優先アクションTOP10、クライアント×商品のニーズ・マトリクス（ヒートマップ） |
| クライアント一覧 | 財務数値と各ニーズの判定結果。並べ替え・絞込み（引継ぎ元事務所／業種／担当／ニーズ度） |
| クライアント詳細 | 判定理由・提案メニュー・試算値（保障不足額、退職金目安、簡易企業価値、取得予算）、進捗管理、面談メモ、印刷 |
| 提案パイプライン | 未着手→提案準備→提案中→成約／見送り のカンバン |
| データ取込・出力 | CSVテンプレート／一括取込、CSV出力、JSONバックアップ・復元 |

## ファイル

- `crosssell/scoring.js` … ニーズ判定ロジック（ルールはここで調整）
- `crosssell/sample-data.js` … デモ用の架空クライアント30社
- `crosssell/app.js` … 画面・操作
- `crosssell/styles.css` … デザイン（ライト／ダーク対応）
