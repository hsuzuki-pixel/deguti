# deguti

YouTube風のホームページを静的ファイルで作成しています。

## 使い方

`index.html` をブラウザで開くと表示できます。

例:

```bash
xdg-open index.html
```

## 幸せ経営コンパス（`lifeplan/index.html`）

社長・幹部のライフプランと経営計画を連動させ、選択理論の5つの欲求で経営者層の幸せを伴走管理する、税理士事務所向けの経営支援ソフトです。ブラウザで開くだけで動きます。

- **この顧問先**：ダッシュボード（業績サマリー・財務アラート）、ライフプラン、経営計画と連動、予算3案・資金繰り、借入金・返済予定（銀行別・融資別）、月次予実・着地予測、財務分析（月次サマリー／予実比較／3期比較／決算予測／資金繰り9か月予測／税額試算／時系列比較／同業比較／損益構造分析／AIアドバイス・相談／AI予算作成／月次レポート）、BS・銀行格付け（参考債務者区分）、幸せ面談、保険診断、提案・出口（ニーズレーダー／提携商品マッチング／資金調達マッチング／資産運用）、M&A・企業価値、会計データ連携（弥生会計・マネーフォワード等の試算表CSV）
- **伴走プログラム**：宿題・年間計画（実行率・年間カレンダー）、伴走の成果（投資対効果・開始時点との比較・成果レポート）、社長ページ（顧問先に渡すスマホ用ページ）、銀行提出資料（事業計画書）、経審シミュレーション（Y点・P点）
- **事務所全体**：顧問先ポートフォリオ（売上・成長率・アラート・ニーズでの横断管理、担当者割り当て）、事務所経営（提携先・紹介実績・利益シミュレーション・KPI）

入力内容はブラウザに自動保存されます。事務所内での共有保存とAI機能は claude.ai 上で開いたときに使えます。
